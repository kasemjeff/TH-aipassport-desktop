# ชุดทดสอบ evals/thai — คู่ไทย/อังกฤษ

ชุดงานวัดความสามารถของโมเดลกับงานภาษาไทยจริง โดยมีคู่อังกฤษเทียบให้เห็นว่า
ความต่างมาจากภาษา ไม่ใช่จากตัวงาน

## โครงสร้าง

- 27 คู่ = 54 งาน: `<id>` (ไทย) และ `<id>-en` (อังกฤษ) งานเดียวกัน คนละภาษา
- `task.json` เพิ่ม key `lang` (`th`|`en`) และ `pair` (id ของคู่) — runner
  อ่านไปใส่แถวรายงาน ไม่ validate
- แต่ละโฟลเดอร์มี `task.md` (โจทย์) + `check.mjs` (ตัวตรวจอัตโนมัติ) ตามแบบ
  `evals/tasks/` ทุกประการ
- ครอบคลุม: งานข้อมูล (พ.ศ./ค.ศ., เลขไทย, วันที่, เงิน, CSV/JSON), งานโค้ด
  สั้น, และงานนโยบายความเป็นส่วนตัว (ชื่อ/ที่อยู่คงสะกดเดิม ห้ามแปล,
  ข้อความห้ามแก้, อักขระล่องหน)

## ที่มาและความเป็นส่วนตัว

- ข้อมูลสังเคราะห์ทั้งหมด เขียนขึ้นสำหรับชุดนี้ ไม่มีข้อมูลบุคคลจริง
- ไม่มีการ import ชุดสาธารณะ: BabelArena, PolyWorkBench, SEATauBench และ
  Typhoon-S เป็นชุดอ้างอิงที่ศึกษาประกอบการออกแบบ แต่ยังไม่ import —
  ต้องตรวจ license ให้ชัดก่อนทุกกรณี
- ห้ามใช้ข้อมูลผู้ใช้จริงในงาน eval ทุกกรณี; ไฟล์ของ attempt อยู่ใน temp

## วิธีรันและตัววัด

```sh
node scripts/evals.mjs --thai --live             # ทั้งชุด
node scripts/evals.mjs --task fix-year --live    # งานเดียว (ไม่ต้องมี --thai)
```

บรรทัด `metrics:` ของสรุปอย่างย่อรายงาน: อัตราสำเร็จ, อัตรา tool call ที่
ผิดพลาด, จำนวน turns/การบล็อกซ้ำ, จำนวนครั้งที่เตือนภาษา, สัดส่วนข้อความ
ตอบที่เป็นไทย และ token ต่องานที่สำเร็จ (ประมาณจาก compactor)

- ชุดนี้ไม่มี replay fixture — fixture ที่มี (`evals/fixtures/`) ใช้กับงานชุด
  `tasks/` เท่านั้น การ replay งานชุดนี้ต้องบันทึก transcript ใหม่
- เกณฑ์ผ่านของแต่ละงานอยู่ใน `check.mjs` ของโฟลเดอร์นั้น ๆ ตัว runner
  ตัดสิน solved/unsolved จาก exit code เท่านั้น
